# Money Miner — Agenthon 2026 Track 2

Development candidates for Team 379. This repository contains only reviewed runtime source, release configuration, official dependency source and its notices. Research datasets, task answers, development API credentials and team-claim keys are excluded.

Three configurations are being validated: adaptive (`shrink`, numerical only), conservative (bounded numerical adaptation), and policy-text (fixed N3 plus a restricted SEP policy-path adjustment). Every output contains 20,000 complete joint scenarios. Optional language-model calls are disabled because development extraction quality has not established a reliable forecast benefit.

Local historical comparisons are development evidence, not official leaderboard scores, statistical significance or organizer eligibility approval. The text mechanism has only two observed interventions in a 14-case diagnostic; it is exploratory.

See [artifact provenance](submission_candidates/release_artifacts/ARTIFACT_PROVENANCE.md) and [release manifest](release-manifest.json). Per-unit estimation, data availability limits and research-selection sources are disclosed there. Build artifacts will identify actual immutable image digests; an image must also pass anonymous pull and container checks before it is used in a submission ZIP.

This repository does not submit to CodaBench or consume a Final attempt. Team proofs are created locally using the official toolkit and are not committed.
